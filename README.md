🌌 3D Scroll Portfolio Website

A modern, interactive 3D scrolling website built using cutting-edge web technologies. This project combines smooth scroll animations with immersive 3D visuals to create an engaging user experience similar to Awwwards-style websites.

🚀 Features:<br>
🎮 Interactive 3D scene (WebGL based)<br>
📜 Scroll-based animations (GSAP)<br>
⚛️ Component-based architecture using HTML, CSS And JavaScript<br>
🌐 Real-time 3D rendering using HTML, CSS And JavaScript<br>
🧩 Simplified 3D integration with HTML, CSS And JavaScript<br>
✨ Smooth UI animations with Framer Motion<br>
📱 Fully responsive design<br>
⚡ Optimized performance for modern browsers

🛠️ Tech Stack:<br>
Frontend: HTML, CSS And JavaScriptt<br>
3D Graphics: HTML, CSS And JavaScript<br>
Animations: GSAP, Framer Motion<br>
Styling: CSS / Tailwind CSS<br>
Version Control: Git & GitHub

⚙️ Installation & Setup:<br>
1. Clone the repository:
git clone https://github.com/your-username/3d-scroll-website.git
2. Navigate to the project folder:
cd 3d-scroll-website
3. Install dependencies:
npm install
Run the development server:
npm start
